# 状態変化あて（jotai-henka）

身のまわりの場面（氷がとける・洗濯物がかわく・冷たいグラスの水滴・ドライアイス など）を見て、物質のすがたの変わり方（融解・凝固・蒸発・凝縮・昇華）を当てる1日5問の学習ゲーム。正解したら「もとのすがたは？」（固体・液体・気体）も選ぶ。中学1年理科「状態変化」。

遊ぶ: <https://satou-aaaaa.github.io/jotai-henka/>

- 中身は大阪府教育委員会の理科プリント（解答）、群馬県・熊本県の教育委員会の指導案、広島県教育委員会の調査問題の解説、岩手県の教材、日本化学会「化学と教育」、宮城県総合教育センター、気象庁仙台管区気象台、札幌市教育委員会、香川大学の指導案で確かめたことだけです。
- 気体から固体への変化は、資料によって呼び名が分かれるので扱いません。このゲームは教科書の代わりではありません。くわしくは教科書で確かめてください。
